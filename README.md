# Control de Línea

Registro de las recorridas de control en las líneas de envasado y del control final,
con un reporte gráfico del día para gerencia. Funciona sin señal y se instala en el celular.

## Uso
1. **Ajustes**: cargá tu nombre y las líneas en el orden en que las recorrés.
2. **Recorrida**: tocá *Iniciar recorrida*. La app te lleva línea por línea; marcá
   Conforme, Ajuste en línea o Sin producción. Si hubo ajuste, completá la *Relevancia del evento*.
3. **Control final**: registrá cada lote terminado antes del despacho.
4. **Reporte**: elegí la jornada y tocá *Exportar PDF* (Guardar como PDF) o *Compartir resumen*.

Los datos quedan en el celular. Descargá un respaldo desde Ajustes cada tanto.

## Publicar en GitHub Pages
1. Crear el repo `controlLinea` y subir todos los archivos de esta carpeta.
2. Settings → Pages → Deploy from branch → `main` / `(root)`.
3. Abrir la URL en Chrome del celular → menú → *Instalar app*.

## Marca
Editar `js/brand.js`: logo (copiarlo a `assets/`), colores y código del registro.
